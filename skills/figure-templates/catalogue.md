# Figure template catalogue

[Template selection and workflow](SKILL.md).

**Graph labels:** `function_graph` accepts optional `x_step` and `y_step`
(positive integers dividing their spans) and `x_label_side="below"|"above"`,
`y_label_side="left"|"right"`. Numerals stay aligned to their ticks; the
builder may flip a whole axis or refuse if no clear arrangement exists.
The numeral for zero binds to the shared origin and aligns with the x-axis
numeral row. If the row cannot fit zero and the question does not need it,
the shared origin is declared unlabelled. Both `function_graph`
and `cartesian_plot` bind point labels and check arrowhead clearance;
`solid` (cylinder/cone radius and height) and `solid_composite` bind dimension
labels to their leaders. See the [hand-drawn API](finish-api.md) for the same
helpers and the visible-mark contract.

### Additional Grade 10/11 profiles

- `frequency_polygon(bounds, freqs, step, v_max, x_ticks="midpoints", closure="zero_neighbours")`
  labels class midpoints only. The zero-frequency neighbours are not labelled;
  use `closure="none"` to omit them.
- `pie_chart(angle_display="given"|"hidden")` requires an explicit choice when
  sectors specify angles. `given` prints whole-degree angles; `hidden` leaves
  them off the figure and records that choice.
- `function_graph(curves={first: {m: 1, c: 0}, second: {m: -1, c: 4}}, intersections=[{name: P, at: [2, 2], curves: [first, second], show_label: false}])`
  checks the point on both curves. The dot remains visible when the label is hidden.
- `parallel_area(base="AB", same_base=True)` checks that all outlines share
  the named or uniquely shared edge. With `parallelogram=True`, each outline
  must be a parallelogram.
- Use `construction(stage="setup")` when the student must construct the result.
  `locus_scene(stage="setup", constraints=[{kind: circle, points: {O: [50, 100]}, distance: 5}, {kind: perp_bisector, points: {A: [0, 0], B: [160, 0]}}])`
  shows only the givens; state the physical distances in the stem. For an
  angle-bisector setup, list the vertex first.
- `scale_drawing(scale={drawn: 1, drawn_unit: cm, real: 5, real_unit: m}, plan={points: {A: [0, 0], B: [6, 0], C: [6, 4]}, segments: [AB, BC, CA]}, scale_bar=10, show="both")`
  uses drawn units for plan coordinates and real units for the bar. Choose
  `show="scale"|"bar"|"both"|"none"`; supply a bar length only when showing it.

### Solved scenes and two-circle geometry

`elevation_scene` and `two_circle_geometry` support `values="stem"|"figure"`.
Figure mode prints the givens and marks them as figure content; stem mode checks
every numeric given. Datum angles and parallel claims use real single-capital
anchors. Numeric marks use `label "<glyph>" names angle<glyph>`; constructed
claims derive the sight complement or r1±r2 touch bounds. Every printed spoke
is declared in `segments:`. A crowded chord-foot letter is omitted only with
a `departures` entry and a `describe` claim, never moved dishonestly.
